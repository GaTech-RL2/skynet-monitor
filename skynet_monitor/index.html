About this view

Shows your running Slurm jobs. Report progress with progress.json, or use compatible config/metrics files. ETA uses recent progress and may change with validation, pauses or retries. GPU load is sampled whole-device utilization; shared devices include other work. VRAM shows this job’s process memory / device capacity, matched by Slurm cgroups and GPU UUID. Unavailable means telemetry could not be attributed or collected. Collection runs on Skynet independently of this browser.
