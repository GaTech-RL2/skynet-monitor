# Contributing

Use Python 3.10+ and the standard library. Keep collection bounded, per-user,
and independent of browser sessions. Avoid site-specific usernames, paths,
credentials, live snapshots and logs in commits or issue reports.

Run both test suites in README.md before opening a pull request. Include the
Slurm/NVIDIA versions and sanitized reproduction data for adapter changes.
Do not claim per-process GPU utilization when only device utilization is available.
